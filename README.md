# Penfold Tradebook
**XAUUSD & USDJPY Quantitative Terminal**

A privacy-first, client-side trading journal designed for quantitative execution and risk management. Built to eliminate spreadsheet friction with instant MetaTrader imports and dynamic risk calculation.

## Core Features
* **Automated MT4/MT5 Import:** Drop in your MetaTrader HTML history report to instantly parse entries, exits, lot sizes, and P&L.
* **Advanced Risk Calculator:** Precision position sizing for Gold and JPY pairs, including support for mental stops and fixed capital allocation.
* **Performance Analytics:** Real-time calculation of Win Rate, Profit Factor, Gross P&L, and Cumulative Equity Curve.
* **Monthly Heatmap Calendar:** Visual P&L tracking with daily trade counts and performance indicators.
* **Privacy First:** 100% local browser storage (`localStorage`). No databases, no external servers, no subscription fees.

## Deployment
Designed to run seamlessly as a standalone web application hosted via GitHub Pages. 

**Mobile Setup:**
1. Navigate to the live GitHub Pages URL on your mobile browser.
2. Tap the browser menu/share button.
3. Select "Add to Home Screen" to use it as a full-screen native application.
